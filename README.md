# Dataset Utilizado

El análisis se desarrolló utilizando datos de la **Gran Encuesta Integrada de Hogares (GEIH 2025)**, publicada por el Departamento Administrativo Nacional de Estadística (DANE).

La GEIH es la principal fuente de información sobre el mercado laboral colombiano y recopila información relacionada con:

- Características demográficas de la población.
- Educación.
- Fuerza de trabajo.
- Ocupación y desempleo.
- Ingresos laborales.
- Condiciones de vivienda y hogar.
- Seguridad social.
- Actividades económicas.

La encuesta utiliza un diseño de muestreo estadístico que permite realizar inferencias sobre la población colombiana y constituye una de las principales fuentes de información para estudios socioeconómicos y análisis del mercado laboral. :contentReference[oaicite:0]{index=0}
